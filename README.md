# etolegko

Скрипт измеряет скорость скачивания ресурса: выполняет 10 последовательных HTTP(S)-запросов, полностью считывая каждый ответ до начала следующего.

Требуется Node.js 18 или новее. Запуск:

```sh
node download-speed.js
```

После запуска введите адрес ресурса, например `https://example.com/image.jpg`, и нажмите Enter.

Результат включает среднее время запроса в миллисекундах, общий объём полученных данных в байтах и среднюю скорость в МиБ/с (1 МиБ = 1 048 576 байт). Скорость рассчитывается как общий объём, делённый на сумму времени запросов, включая ожидание ответа и загрузку тела. При сжатии HTTP учитывается размер распакованного тела ответа. Перенаправления обрабатываются автоматически; при ошибке запроса или HTTP-статусе вне диапазона 2xx скрипт завершается с ошибкой.
